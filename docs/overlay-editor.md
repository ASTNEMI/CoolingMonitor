# 悬浮窗与编辑器

## 使用

1. 打开「悬浮窗」，从八种内置预设选择初始布局。
2. 在画布点选组件。选择「移动」直接拖动，选择「缩放组件」拖动以右下角为调整方向。关闭网格可连续移动，也能直接编辑尺寸和坐标。
3. 可添加数值、单位、标签、连接状态、指示灯、分隔线、温度曲线及容器。组件属性包括数据来源、层级、粗体、字号、文字与背景颜色、边框、圆角、内边距、可见性。按钮支持居中或按间距进行横向、纵向排列。
4. 点击「应用布局」更新窗口。可保存命名预设，或导入 / 导出 JSON。撤销和重做覆盖预设、编辑以及整次拖动。
5. 已显示的窗口支持拖放、双指缩放、点按折叠、吸边和锁定。触摸穿透通过应用内按钮或监控通知恢复，Android 12+ 按系统允许的遮挡透明度配置。

## 坐标与窗口

画布布局的逻辑单位是 dp。预览与悬浮窗均调用 `OverlayDrawing`，按实际窗口与逻辑宽度比例转换坐标。移动过程中累计原始位移，再独立计算吸附位置。窗口位置存成可用空间内的比例，竖屏与横屏分别存储。Android 11+ 使用 WindowMetrics 的系统栏和缺口 Insets，早期版本使用显示尺寸与状态栏高度。

## 导入与导出

JSON 格式版本为 1。文件保存窗口宽高、颜色、透明度、缩放、圆角、间距、吸附、触摸模式、跟随应用风格选项和组件数组。颜色为 ARGB 整数。导入最大 100,000 字符和 32 个组件。组件坐标与尺寸被限制在画布内，导入后在编辑器内预览并手动应用。导入会以普通可移动模式打开。

## 渲染边界

系统窗口通过 `TYPE_APPLICATION_OVERLAY` 实现。安全应用、权限界面和特定游戏可以隐藏第三方悬浮窗。悬浮窗默认继承 ColorOS 或 Liquid Glass，布局可关闭「跟随应用界面风格」。折射来自悬浮窗自己的 Compose 图层，场景保留窗口整体透明度。透明文本预设只显示文本。其他应用画面由 Android 合成器管理。
