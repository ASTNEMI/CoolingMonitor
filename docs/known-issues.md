# 当前限制与待核对项

- 当前定位为 CX2 Pro 首版。已有实物协议代码的静态证据，仍需连接同型号散热器确认扫描、实时读数、温度传感器位置、固件差异、配对和官方 App 的多连接行为。
- 仅实现温度一条趋势曲线。功率、风扇档位、开关等显示真实解码值，请按验证表比对实机。水泵、制冷端、进出水温、RPM、电压、电流和故障码仍缺少映射依据。
- 系统、厂商的电池策略以及特定游戏是否隐藏悬浮窗需要在目标设备验证。进程被系统终止后由用户重新打开应用恢复，服务不设开机自动启动。
- Backdrop 折射在 Android 13+ 的同一应用窗口启用。系统悬浮窗可折射窗口内图层。跨 App 界面由系统合成器管理。
- 历史海量写入、后台 2 小时压力和温度曲线在真实持续数据下的稳定性未获实机测量。应用没有测量丢包率所需的设备帧序号。
- ColorOS 17 与真实平板的系统栏、游戏覆盖、字体、手势和 GPU 表现待测。此次改版没有取得可复核的原生界面截图。
- 模拟器只用于原生 UI、权限和窗口流程。解析器测试的响应字节按已知映射人工构造，没有实机帧夹具。
